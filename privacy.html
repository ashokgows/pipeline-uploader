Privacy Policy

Effective 8 November 2026

What this application is

YouTube Pipeline Uploader ("the application") is a personal-use desktop program operated by a single individual (the "operator") to publish and manage content on the operator's own YouTube channels. There are no other users.

Data the application accesses

With the operator's consent through Google OAuth, the application uses the YouTube Data API (scope https://www.googleapis.com/auth/youtube) to: upload videos and thumbnails; set video titles, descriptions, tags, privacy status and scheduled publish times; create and manage playlists; read and update channel branding, descriptions and settings; and read basic channel and video information. All of this concerns channels owned by the operator.

Data storage

OAuth tokens are stored only in files on the operator's own computer. No data is transmitted to any server other than Google's APIs. The application has no database, no analytics, no advertising and no third-party integrations.

Data sharing

The application does not sell, share or disclose any Google user data to third parties. It does not use Google user data for advertising, credit-worthiness assessment, or to train machine-learning models.

Google API Services User Data Policy

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time from myaccount.google.com/permissions. Deleting the locally stored token files removes all data the application holds.

Changes and contact

Changes to this policy are published on this page. Questions can be raised by opening an issue on the GitHub repository that hosts this site.
